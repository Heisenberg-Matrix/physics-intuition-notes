# 单位圆 · sin 单角变换

基于 **Vite + TypeScript + SVG** 的交互式三角学教学 demo，帮助学生建立「单角变换」(诱导公式) 的几何直觉。

- 拖动圆周点，或拉动 θ 滑块，改变角度。
- 用 `sign ∈ {+1, −1}` 与整数 `k` 组合，演示
  `θ′ = sign·θ + k·180°` 对应的 sin 变换。
- sin 始终用同一种陶土橙表现：**颜色只代表「这是 sin」，正负由投影位置与数值符号表达**。
- 可隐藏坐标系，或隐藏原角 θ 的淡化虚线参照。

## 运行

```bash
cd animations/unit-circle
npm install
npm run dev        # 打开 http://localhost:5173/
npm run build      # 产物在 dist/
```

本 demo 采用 Vite + TypeScript（按任务要求），与仓库其它纯静态 demo 不同，
需要构建后才能托管；`dist/` 不入库。

## 数学设定

- 单位圆半径 `R = 270`(SVG 像素)，圆心为 viewBox 原点 `(0,0)`，y 轴取反以符合数学逆时针。
- 圆上点：`(R·cosθ, −R·sinθ)`。
- 单角变换：`θ′ = sign·θ + kπ`。
- 拖动交互：圆周点实测位於 θ′，反解原角 `θ = sign·(θ′ − kπ)`。

## 可调参数

| 控件 | 范围 | 意义 |
|------|------|------|
| θ 滑块 | 0–360° | 原角 |
| sign | ±1 | 反映 |
| k | −6–6 整数 | 加 kπ |
| 显示坐标系 | 开/关 | 关闭后保留圆、射线、投影 |
| 显示原角参照 | 开/关 | θ 端点处淡化虚线 |

## 边界与假设

- k 取整; 超大 k 不影响几何坐标（cos/sin 周期）。
- 关闭坐标系不影响圆的几何计算——几何全部由 `math.ts` 同一套状态驱动。
- 高 DIP 由 SVG viewBox 自适应，无需手动 resize 处理。

## 验证

- `tsc` 严格类型通过；Vite build 通过。
- 浏览器实测（patchright + headless Chromium，端口 5199）：
  - 8 种 sign×k̂ 组合的 sin 值与 `sin(sign·θ + k·180°)` 逐位一致；
  - 拖动画布圆周点反解 θ 闭合正确（命中 θ′=250° → θ=290°）；
  - 关闭坐标系后 `g.axis` 隐藏，但圆、活动层、投影仍存在；
  - 终端无 console 错误、无加载请求失败。
- 未做人类视觉检查（本环境中无法把截图回读给模型），但 computed style 校验过纸张底色、陶土橙投影、虚线参照等关键样式。

## 物理假设

纯数学演示，无物理模拟；不涉及力的概念。s=sin 与投影始终满足 `|sinθ| ≤ 1`。
