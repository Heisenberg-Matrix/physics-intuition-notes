# Sum 1→n — 视觉证明动画

用 Manim Community Edition 制作的竖屏无字证明：阶梯只画出前几行（1、2、3）与第 `n` 行，中间被省略的行用 `⋮` 表示；把这份阶梯复制一份、旋转 180° 并平移，两块阶梯恰好拼成 `n × (n + 1)` 的长方形，于是总和是 `n(n + 1) / 2`。

成片：[sum-1-to-n.mp4](sum-1-to-n.mp4)（1080×1920，60 fps，约 15.9 秒，无音轨）

## 预览

直接用浏览器打开 [index.html](index.html)，或在本仓库根目录启动静态服务器：

```bash
python -m http.server 8123
# http://localhost:8123/animations/sum-1-to-n/
```

视频用浏览器原生播放，页面无外部依赖。

## 渲染

依赖：Python 3.9+、Manim CE（本仓库用 0.19.1 验证）、`ffmpeg` 在 `PATH` 中。

```bash
cd animations/sum-1-to-n
python -m manim sum_one_to_n.py SumOneToN
```

输出在 `media/videos/sum_one_to_n/1920p60/SumOneToN.mp4`。分辨率、帧率、画幅已在脚本顶部通过 `config` 固定为 1080×1920 / 60 fps / 9×16 场景单位，无需额外命令行参数。

只检查最后一帧：

```bash
python -m manim sum_one_to_n.py SumOneToN -s
```

## 涉及参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `N` | `5` | 最后一行的行号；实际数学行长为 1…`N` |
| `TOP_ROWS` | `(1, 2, 3)` | 省略号之前实际绘制的行 |
| `GRID_WIDTH` | `6.0` | `n + 1` 列的总宽（场景单位），`cell = GRID_WIDTH / (n + 1)` |
| `Y_CENTER` | `1.4` | 可见块的竖直中心，与第 3 行重合 |
| 小球半径 | `0.40 · cell` | 留出 0.20 的哑光间隙 |
| 背景 / 青绿 / 陶土 | `#FAF6EF` / `#6FA79D` / `#C98A6E` | 暖白与低饱和双色，边缘加深色描边 |
| 字体 | `Microsoft YaHei` / `Georgia` | 省略号与中文标注 / 数字与公式；变量 `n` 用 `<i>` 斜体 |

`N` 由数据层传入 `StaircaseLayout`（`@dataclass(frozen=True)`），所有坐标、行与列都由它推导，渲染代码不硬编码行数。脚本要求 `N ≥ TOP_ROWS[-1] + 2`，即省略号至少代表一行。改 `N` 时整体宽度固定、`cell` 随之变化，纵向高度为 `5 · cell`。

## 几何与动画说明

- 数学上有 `N` 行；屏幕上只绘制 `1、2、3、N` 四行，中间 `N - 4` 行折叠进一条省略号带（高度 1 个 `cell`），所以最终长方形是「3 个可见行 + 1 个空带 + 第 `n` 行」共 `5 · cell` 高；
- 第 3 行取在块中心，第 `n` 行满足 `y_n = 2·y_3 − y_1`。这样复制品绕自身中心旋转 180° 后：第 3 行原地不动，第 2 行恰好落进省略号带，第 1 行与第 `n` 行互换；再向右平移一个 `cell`，补集行就右对齐到第 `row … n` 列；
- 落进省略号带的复制行淡出，保持空带为空；由隐藏行补出的球（第 2 行的全部、第 3 行的中段）在最终位置淡入。最终每一可见行都是 `n + 1` 个球：左侧青绿为原阶梯，右侧陶土为补集；
- 开始时逐行长出 1、2、3 行，随后整体上移 `0.35 · cell` 的间距让出省略号带并淡入 `⋮`，最后一行以具体数字 `N` 出现、标签再 `FadeTransform` 成斜体 `n`；
- 时间线（`TIMING` 表，单位秒）：阶梯、布局过渡与标签变形约 4.25 → 复制、旋转、平移与拼接约 3.55 → 长方形与行列标注约 2.6 → 公式淡入 1.2 + 停留 3.3，合计约 15.9 秒。

动画不使用 LaTeX（无 `Tex` / `MathTex`），公式由 `MarkupText` + Pango 斜体标签排版，可直接渲染 MP4。
