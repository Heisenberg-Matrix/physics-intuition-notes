# 动画与交互实验

动画是帮助建立心智图像的手段，而不是目的。

优先研究并复用已有的优秀开源工具；需要原创时保留源文件、运行方法、物理假设以及对应讲义链接。

一个有效的动画应当帮助读者在关闭动画后，仍能独立预测物理过程。

## 实验列表

- [Water Lab — 2D 粒子水流交互实验](water-lab/README.md)：斜抛 / 平抛 + Metaball 融球水流的实时物理 Demo，可调发射角度、力度、重力、发射率等参数。
- [一个球 — Sphere 球体](sphere/README.md)：Three.js `SphereGeometry` 手作质感球体，哑光材质、柔和自然光与落地投影，可拖动观察。
- [单位圆 · sin 单角变换](unit-circle/README.md)：Vite + TypeScript + SVG 交互式单位圆，拖动圆周点或滑块调整 θ，演示 θ′= sign·θ + kπ 的 sin 投影，可隐藏坐标系与原角参照。
- [Sum 1→n — 中文解说视觉证明](sum-1-to-n/README.md)：Manim 竖屏证明动画，省略号压缩阶梯复制旋转 180° 拼成 n×(n+1) 长方形，配中文解说与 BGM，导出 1080×1920 MP4。
- [对角线和 — 1+2+…+n+…+2+1 = n²](diagonal-sum/README.md)：Manim 手绘铅笔风竖屏短片，5×5 方阵沿斜线数出 1…5…1，拼成 n²；配中文解说、关键词字幕与极轻音效，约 29 秒。
- [平方和 · 三个阶梯体积木](square-sum-3d/README.md)：Manim 三维竖屏短片，n=4 的三份平方阶梯体只做整体旋转与平移，拼成长方体；再把顶层切开补成半高，用 4×5×4½ 的体积推出平方和公式；配中文解说与字幕，约 70 秒。
- [三角诱导公式 · 单位圆旋转](trig-reduction/README.md)：Manim 竖屏短片，先完整讲正弦（转半圈、取负角、关于纵轴），再按同样顺序讲余弦，不穿插；保留原角度与正负号，用三种变换解释诱导公式；中文配音与字幕，约 69 秒。
- [谁规定一圈必须是 360°？· 弧度制](radian-2pi/README.md)：Manim 竖屏短片，把“一圈记成几份”还原成可改的选择，用圈数表示任意角；由“量弧长”的需求推出 `s = 2πr·θ/N`，再令换算系数为 1、得 `N = 2π`，公式只剩 `s = rθ`；半径当软尺量弧，解释弧度制“一个数字，两种用途”；中文配音与字幕，约 175 秒。
- [高轨低速大周期 · 卫星圆轨道](orbit-speed-period/README.md)：Manim 竖屏短片，不要求背口诀：同位置引力加速度与卫星质量无关，`r` 翻倍则 `a` 变四分之一；再与圆周运动的 `a = v²/r` 联立解出 `v = √(GM/r)`；两颗卫星按真实比例同时起跑，用“路程更长、速度更慢”推出 `T` 更大，最后回到开场选择题；中文配音、字幕与轻音乐，约 92 秒。
