# Sphere — 从四周观察球体

用 Three.js 的 `SphereGeometry` 画一个可以从任意方向观察的球体。拖动旋转、滚轮缩放；右上角实时显示相机方位角与仰角。

## 运行

```bash
cd <仓库根目录>
python -m http.server 8123
```

打开 <http://localhost:8123/animations/sphere/>。无需构建步骤，也不需要后端。

Three.js（r160.1）和 `OrbitControls` 已放在 `vendor/three/` 中，不依赖 CDN，可离线运行，也可直接部署到静态站点。代价是仓库里多出约 690 KB 的第三方代码（`three.module.min.js` 约 655 KB，`OrbitControls.js` 约 31 KB）；这是本 demo 唯一的外部运行时依赖，保留上游 MIT 许可证。

## 操作

- **拖动**：绕球体旋转视角。
- **滚轮 / 双指捏合**：缩放。
- **自动旋转**：默认开启（系统设置「减少动态效果」时默认关闭）。一旦拖动或缩放，会自动停止，方便仔细观察；可再次点击恢复。
- **经纬网**：显示/隐藏球面上的经线与纬线，用来感知球的朝向。
- **重置视角**：回到初始角度。
- 平移已禁用，保证球体始终位于画面中央。

## 实现要点

- 球体：`SphereGeometry(1, 128, 96)`，半径 1，128 个经向分段、96 个纬向分段。
- 相机：透视相机，垂直视场角 42°；`OrbitControls` 带阻尼，围绕原点旋转。
- 材质：`MeshPhysicalMaterial`，配合暖色主光、冷色补光和青色轮廓光。
- 渲染：WebGL 抗锯齿，像素比上限 2，`ResizeObserver` 跟随窗口变化；根据视口宽高动态调整相机距离，确保球体在桌面和手机上都不被标题、工具栏遮挡。
- 经纬网是画在球面外 `r × 1.0025` 处的示意线（30° 纬线间隔、12 条经线），不是真实地理坐标。
- 这是一个纯几何演示，没有物理模拟；半径 1 是任意单位。球体轮廓从任何方向看都相同，变化的是表面上经纬网的朝向。

- 页面返回 200，控制台无报错或警告，所有资源请求成功。
- 检查了 1280×720、1024×768、390×844、1600×900 四种视口，标题、球体和工具栏无重叠，Canvas 的 WebGL 上下文正常。
- 交互测试通过：暂停自动旋转后，拖动使方位角从 0° 变到 −55°、仰角从 9° 变到 26°；经纬网开关状态正确切换；重置视角回到仰角 9°。截图确认球体和经纬网正常渲染。
