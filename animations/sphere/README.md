# 一个球 — Sphere

用 Three.js 的 `SphereGeometry` 画一个可以拖动观察的手作质感球体。视觉上参考《Untitled Goose Game》：暖米色纸面、低饱和的陶土绿、哑光材质、柔和自然光和真实的落地投影，不做写实反射，也没有科技感光效。

## 运行

```bash
cd <仓库根目录>
python -m http.server 8123
```

打开 <http://localhost:8123/animations/sphere/>。无需构建，也不需要后端。

Three.js（r160.1）和 `OrbitControls` 放在 `vendor/three/` 中，不依赖 CDN，可离线运行。第三方代码约 690 KB（`three.module.min.js` 约 655 KB、`OrbitControls.js` 约 31 KB），保留上游 MIT 许可证。

## 操作

- **拖动**：绕球体旋转视角。
- **滚轮 / 双指捏合**：缩放。
- **自动旋转**：让球体缓慢自转。开始拖动或缩放时会自动停下，方便观察；可再次点击恢复。系统开启「减少动态效果」时默认关闭。
- **重置视角**：恢复初始相机角度和球体朝向。

## 实现要点

- 球体：`SphereGeometry(1, 128, 96)`，半径 1。
- 材质：`MeshStandardMaterial`，`roughness: 0.93`、`metalness: 0`；表面使用程序生成的 CanvasTexture（低对比色斑 + 细小颗粒）和轻微 bump map，避免默认几何体的塑料感。纹理在水平方向做了接缝处理。
- 光照：暖色主光（带实时软阴影）、冷色补光、背后轮廓光，以及暖色半球光。地面用 `ShadowMaterial` 接住投影，不显示地板本身。
- 构图：相机略高于球心，始终从上方或水平方向观察，不会钻到地面以下。球体大小随视口调整，给标题和底部控件留出空间；背景保持大面积留白。
- 页面背景是 CSS 米色纸面，并叠加很淡的纸张颗粒；WebGL 画布透明叠在上面。

### 后续扩展位置

- 场景中的球体在 `globe` 组内，球心位于 `(0, 1, 0)`，地面为 `y = 0`；切平面、纬线等可以直接挂到 `globe` 上，以球心为原点布局。
- 底部 `.toolbar` 只放了两个按钮，可继续加「纬线」「切平面」等开关。
- 地面阴影接收面已经独立存在；新增物体时给它们设置 `castShadow` 即可融入同一光影。
