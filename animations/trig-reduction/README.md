# 三角函数诱导公式，真的需要背吗？

一条 69 秒的竖屏动画，配中文配音与字幕。它先把正弦完整讲一遍：入门、转半圈、取负角、关于纵轴对称；正弦全部讲完后，再按同样的顺序讲余弦，不把 sin 和 cos 穿插在一起。每一步都保留 α 处的原投影和 +/− 号，转多少、镜像到哪，都连续画出来。

正弦线：

- 先把点 P 放到单位圆上，只画纵坐标，得到 `+sin α`；
- 逆时针转半圈到 π+α：原位置的 `+sin α` 保留，新位置标 `−sin α`；
- 回到 α 后顺时针转到 −α：纵坐标变号，正弦也变号；
- 关于纵轴对称到 π−α：纵坐标不变，正弦不变。

余弦线按同样的四步再走一遍，只画横坐标：

- α 处 `+cos α`；π+α 处 `−cos α`；
- −α 处横坐标不变，仍是 `+cos α`；
- π−α 关于纵轴对称，横坐标变号，得到 `−cos α`。

最后让 α、−α、π−α、π+α 四个点同时留在圆上，比较三种变换，再列出公式：

```text
sin(kπ + α) = (−1)^k sin α
sin(kπ − α) = (−1)^(k+1) sin α
cos(kπ ± α) = (−1)^k cos α        (k ∈ ℤ)
```

成片：[trig-reduction.mp4](trig-reduction.mp4)（1080×1920，30 fps，69 秒，AAC 48 kHz 单声道配音）。

## 预览

直接用浏览器打开 [index.html](index.html)，或在仓库根目录启动静态服务器：

```bash
python -m http.server 8123
# http://localhost:8123/animations/trig-reduction/
```

## 渲染

依赖：Python 3.10+、Manim CE 0.19.1、NumPy、edge-tts 7.3.1（配音，需联网）、FFmpeg（写 MP4 与混音）。本仓库已在 Manim 0.19.1 + Python 3.10.11 + edge-tts 7.3.1 下验证。

```bash
cd animations/trig-reduction
pip install -r requirements.txt

./run.sh preview     # 540×960 @30，输出 media/preview.mp4（含配音）
./run.sh             # 1080×1920 @30，输出 trig-reduction.mp4 与 poster.jpg（含配音）
```

等价的 Manim 命令：

```bash
# 低清预览（无声）
PREVIEW=1 python -m manim -ql --disable_caching scene.py TrigReductionScene

# 成片（Manim 按画面高度命名输出目录，竖屏 1080×1920 是 1920p30）
python -m manim -qh --disable_caching scene.py TrigReductionScene

# 配音：逐句合成，命中缓存后不再联网
python narration.py

# 把音轨混进视频
ffmpeg -i media/videos/scene/1920p30/TrigReductionScene.mp4 \
  -i media/voice/voiceover.wav -map 0:v:0 -map 1:a:0 -c:v copy \
  -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:a aac -b:a 128k -ar 48000 -ac 1 \
  -movflags +faststart -shortest trig-reduction.mp4
```

`--disable_caching` 建议保留：本片大量使用 `always_redraw`，分段缓存不能完整记录 updater 状态，复用旧分段容易出现错帧。

## 配音

- **音色**：`zh-CN-XiaoxiaoNeural`，语速 `+4%`；逐句合成后用 20 ms 淡入淡出拼进 69 秒音轨。
- **文本来源**：直接读 `scene.py` 的 `CUES`，字幕和语音不会各写一份。文案直接用“正弦 / 余弦”，不再把 `sin`、`cos` 读成“赛因 / 扣赛因”；`PRONOUNCE` 只在文案里出现英文函数名时兜底替换。
- **对齐**：`ONSETS` 记录画面中每句字幕实际淡入完成的秒数；语音从该时刻起播，若上一句还没说完就顺延，保证不重叠（本片最多把某句顺延 0.22 秒）。
- **响度**：混流时 `loudnorm=I=-16:TP=-1.5`，符合短视频平台常见的 −16 LUFS 目标。
- **缓存**：每句 MP3 按文本哈希缓存在 `media/voice/`，改一句只会重合成那一句；首次合成需联网。
- **无背景音乐**：只保留人声，避免和关键词字幕抢注意力。

## 实现要点

- **先正弦、后余弦**：两遍走的是同一套四步（入门、π+α、−α、π−α）。`sin_a` / `cos_a` 分别控制纵、横投影的透明度，`hl_sin` / `hl_cos` 控制加粗高亮；转场时先把上一遍的标签、公式、虚线和投影一起收走，画面回到 α 再开始下一遍，观众不会同时看到两条投影。
- **保留原角度**：转半圈或转到负角之前，先在 α 处留下浅色对照点和 `ghost_projection`（细投影线 + `+sin α` / `+cos α`），新位置再用高饱和色标 `−sin α` / `−cos α`，正负号始终同时可见。
- **标签不压线**：正弦标签按点的左右位置放到半径的另一侧；余弦标签按点在横轴上方还是下方换边——点在下半圆时标签放到轴上方。`cos(−α)` 段两个 `+cos α` 数值相同、位置重合，因此都放在横轴上方并上下错开。
- **连续旋转**：`ValueTracker` 保存弧度，半径、动点、两条投影线都用 `always_redraw` 跟随；转半圈是 `α → α+π` 的插值，不是换点。
- **转向弧画在圆外**：角度弧的半径设为 `RADIUS + 0.16`。若正好画在圆周上，会被同宽的黑色圆线整条盖住，只剩箭头；放到圆外后，逆时针、顺时针和镜像的方向都能看清。每段结束都淡出弧线，片尾不会留下箭头。
- **一次只强调一个关系**：合并段用“虚线 + 两个圆环 + 一句说明”依次比较 π−α、π+α、−α；每次只停留一个关系。
- **颜色**：青绿 `#299C8D` 是原始角，橙黄 `#D6A04D` 是负角点，蓝 `#648BCB` 是关于纵轴的镜像点，玫红 `#C67591` 是对径点；与公式、字幕的颜色分工一致。
- **安全区**：所有公式与字幕限制在竖屏中央约 7.3 个画幅单位内（左右各留约 8% 空白）；单位圆圆心固定，全片不切镜头。
- **投影线用细实线**：`always_redraw` 每帧重建 `DashedLine` 时虚线数量会变化，Manim 的 `become/align_points` 在子路径数不一致时会抛出 `IndexError` 并卡住；改用同色细实线，画面也更干净。
- **公式排版**：本机没有 LaTeX 时，`math_text` 自动退回 Cambria Math 的 `MarkupText`（`sin`、`cos` 用斜体标记）；有 LaTeX 时优先用 `MathTex`，两条路径内容一致。

## 验证情况

- **渲染**：Manim 0.19.1 完整渲染 540×960@30 预览与 1080×1920@30 成片，单场景连续渲染，时长 69.00 秒；成片约 5.9 MB，视频 1080×1920@30，音轨 AAC 48 kHz 单声道。`./run.sh preview` 与 `./run.sh` 均已跑通。
- **数学**：α=40°；π+α=220° 落在第三象限，π−α=140° 落在第二象限，−α=−40° 落在第四象限；四条分段结论与三条最终公式均与 `k` 的奇偶一致。
- **逐帧抽查**：正弦四段只出现纵坐标投影，余弦四段只出现横坐标投影；`π+α`、`−α`、`π−α` 三处都同时保留 α 处的浅色对照与 `+sin α` / `+cos α` 标签；`cos(−α)` 段两个 `+cos α` 上下分开；合并段四条半径、四个点同时在场；片尾只剩单位圆、三条公式与“余弦同理 · k 为任意整数”。
- **标签与弧线**：余弦标签在点落到下半圆时自动换到横轴上方，不再被半径穿过；角度弧画在圆外，转半圈与镜像的箭头方向可辨，且每段结束都会淡出，片尾没有残留箭头。
- **安全边距**：540×960 与 1080×1920 下最左/最右内容均留有约 8% 画幅宽度；字幕与公式不重叠，片尾公式停留约 3 秒。
- **配音**：17 句按字幕时刻起播，互不重叠；最多顺延 0.22 秒。首句约 0.40 秒起声，末句约 68.31 秒收尾；成片实测 −16.2 LUFS、真峰值 −1.5 dBFS，片尾留约 0.7 秒静默定格。
- **已知限制**：本机无 LaTeX，公式字形为 Cambria Math；Edge TTS 首次合成需要联网，没有背景音乐。
