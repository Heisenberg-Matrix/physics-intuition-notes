# Water Lab — 2D 粒子水流交互实验

## 一、项目目标

开发一个运行在浏览器中的 2D 粒子水流 Demo。

参考《鳄鱼小顽皮爱洗澡》（Where's My Water?）的卡通液体质感，实现一股连续、自然、具有粒子感的水流。

水流从指定位置以指定初速度发射，在重力作用下运动，撞击地面后产生水花并消散。

这是未来交互式物理教材中的核心组件。当前阶段只验证水流物理与视觉效果，不需要制作完整小游戏。

**最终交付一个真正可运行、可以实时调参的网页，而不是静态设计图或预渲染动画。**

## 二、技术栈

- HTML5 + CSS3
- 原生 JavaScript（ES Modules）
- Canvas 2D API
- requestAnimationFrame

不使用 Three.js、React、PixiJS 或第三方物理引擎。

不需要后端，尽量减少外部依赖。

物理计算与视觉渲染应保持分离，方便未来嵌入已有的水龙头原型图。

## 三、核心功能

### 1. 粒子水流

使用二维粒子发射器生成连续水流。

每个粒子具有位置、速度、半径和生命周期。

粒子从可配置的发射点产生，具有初始水平速度和竖直速度，受重力影响。

采用屏幕坐标系，Y 轴向下为正。

要求：

- 粒子遵循正确的抛体运动规律。
- 支持持续发射和停止发射。
- 允许适当随机扰动，使水流更自然。
- 关闭发射后，已生成的粒子继续运动。
- 运动效果不应明显依赖屏幕刷新率。
- 粒子超出边界或生命周期结束后自动清理。

### 2. 水流视觉融合

**这是本项目的重点之一。**

水流不能看起来像一串分散的蓝色圆点。

需要让相邻粒子在视觉上融合，形成柔软、连续的卡通液体形态，同时保留少量颗粒感。

参考 Metaball（融球）效果：

- 相邻粒子自然连接。
- 水流轮廓相对清晰。
- 水流边缘具有细微变化。
- 整体保持清澈的浅蓝色。
- 不要过度模糊，也不要变成一根完全平滑的固定水柱。

优先使用 Canvas 2D 实现。如果采用离屏 Canvas、模糊和阈值处理，请关注性能与画面清晰度。

允许使用合理的视觉近似，不要求真实流体求解。

### 3. 地面碰撞与水花

设置一条水平地面碰撞线。

当水流粒子撞击地面时，原粒子消失，并在碰撞位置产生水花。

水花采用：

**融合的液体主体 + 少量独立飞溅水滴。**

要求：

- 撞击瞬间产生短暂的横向扩散效果。
- 少量水滴向上、向两侧飞溅。
- 飞溅水滴受重力影响。
- 水花自然消散，不需要积水。
- 水花强度与撞击速度相关。
- 持续流水时，水花应连续自然，不能出现密集、重复的爆炸效果。

水花整体应轻盈、有弹性，带有卡通游戏的视觉质感。

### 4. 实时参数调节

在网页中提供简洁的参数面板。

必须支持：

| 参数 | 说明 |
|---|---|
| startX | 发射位置 X |
| startY | 发射位置 Y |
| velocityX | 水平初速度 |
| velocityY | 竖直初速度 |
| gravity | 重力加速度 |
| emissionRate | 每秒发射粒子数量 |
| particleRadius | 水粒子大小 |
| groundY | 地面高度 |

位置使用逻辑像素，速度使用逻辑像素/秒，重力使用逻辑像素/秒²。

参数通过滑块实时调整，并显示当前数值。

支持直接拖动发射点改变位置。

提供以下操作：

- 开启 / 关闭水流
- 暂停 / 继续
- 重置

参数面板以实用、易调试为主，不需要复杂的 UI 设计。

## 四、视觉要求

整体采用简洁的 2D 物理实验台风格。

- 浅色背景。
- 清澈的蓝色水流。
- 简单的水平地面。
- 水流具有融合感和颗粒感。
- 水花自然、柔和。
- 动画流畅，不要机械重复。

不需要绘制水龙头、土地、复杂背景或装饰元素。

重点打磨水本身的运动和视觉效果。

## 五、工程要求

1. 物理计算和渲染分离。
2. 代码清晰，避免不必要的抽象和过度工程化。
3. 使用合理的时间步长处理，保证运动稳定。
4. 限制粒子数量，避免内存无限增长。
5. 正确处理窗口尺寸变化和高 DPI 屏幕。
6. 碰撞检测应避免高速粒子直接穿过地面。
7. 暂停时物理状态保持不变。
8. 提供方便后续调用的发射器参数接口。
9. 尽量保证桌面浏览器中流畅运行。

## 六、验收标准

交付前请重点检查以下三项：

**A. 物理正确性**

- 改变初速度，水流轨迹正确变化。
- 改变重力，水流下落轨迹正确变化。
- 改变发射点，水流从新位置产生。
- 停止发射后，已有水粒子继续运动并最终消失。

**B. 水流视觉效果**

- 水流具有连续的液体形态。
- 相邻粒子自然融合。
- 不出现明显的蓝色珠子串。
- 水流运动自然，具有轻微颗粒变化。

**C. 水花效果**

- 水粒子撞击地面后产生水花。
- 水花包含融合主体和独立飞溅水滴。
- 水花大小随撞击速度合理变化。
- 水花自然消散，没有无限积累或明显卡顿。

请实际运行并检查能验证的功能。如果无法运行浏览器或进行视觉检查，请明确说明，不要虚构测试结果。
