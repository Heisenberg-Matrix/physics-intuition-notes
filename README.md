# 物理直观讲义 | Physics Intuition Notes

> 理解物理，不止于记住公式。

这是一个长期连载的个人物理讲义项目：把自己真正理解的物理概念，以文字、数学推导、图像、动画、交互实验和教学设计的形式留下来，帮助曾经困惑的自己，也帮助后来学习物理的人。

## 内容目录

- [高中物理 · 基础知识讲义](high-school/fundamentals/README.md)：概念、公式、物理图像、适用条件与误区。
- [高中物理 · 高考重点模型](high-school/gaokao-models/README.md)：建模、过程分析、临界条件和模型迁移。
- [大学物理](university/README.md)：连接物理直观、数学推导与理论结构。
- [动画与交互实验](animations/README.md)：把抽象过程变得可观察、可操作（含 Water Lab 水流交互 Demo）。
- [教案与教学设计](teaching/README.md)：研究学生的理解障碍和教学反馈。

## 创作原则

1. **先理解，再解释**：内容经作者核对，持续修正错误。
2. **直观与严谨并重**：图像、类比、动画不替代适用条件和推导。
3. **真正理解意味着能够预测**：关闭动画后，读者仍能在脑中运行物理过程，并预测条件变化后的结果。
4. **长期主义**：以至少三年的持续学习和创作为目标，不追求短期高产。
5. **先复用，再创造**：优先研究已有教材、开源工具和优秀解释，再进行有价值的原创。
6. **保留作者性**：记录思考过程、修订历史与原创贡献。
